# Agent memory

A copy of the notes Claude Code keeps about this project between sessions:
the owner's preferences, decisions, gotchas found while testing, and where
each plan stands. They live in Claude Code's own memory folder and are copied
here at checkpoints so they're versioned with the code.

- `MEMORY.md` is the index: one line per note.
- Each other file holds one fact, with a **Why** and a **How to apply**.
- `[[name]]` links point to another note by its `name:`.

Read these with `TO_BE_DONE.md` at the repo root. Its "▶ RESUME HERE" block
is the live log of what's done and what's next. The plan documents are under
`docs/` (`docs/desktop-control/PLAN.md`, `docs/unify/`).

They're a snapshot. A note may be out of date by the time you read it, so
check any file, function or flag it names before you rely on it.
